# Example Data for OSL Bayesian Age Model

Example Data for OSL Bayesian Age Model

## Usage

``` r
OSLJingbian
```

## Format

A list with 7 elements :

- ThetaMatrix:

  The Theta Matrix Covariance for dose rate errors

- D:

  Equivalent doses

- sD:

  Equivalent doses errors

- Nb_sample:

  Jingbian OSL sample size

- SampleNames:

  Jingbian OSL sample names

- Output:

  Jingbian OSL Unconstrained Bayesian Output
