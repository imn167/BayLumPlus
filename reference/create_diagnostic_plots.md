# Create MCMC diagnostic plots for AgeS_Computation / Compute_Ages functions

Create MCMC diagnostic plots for AgeS_Computation / Compute_Ages
functions

## Usage

``` r
create_diagnostic_plots(echantillon, SampleNames)
```

## Arguments

- echantillon:

  MCMC object from runjags

- SampleNames:

  Character vector of sample names

## Value

List of ggplot/plot objects that can be displayed or saved
