# Example Data for Bayesian Age Model

Example Data for Bayesian Age Model

## Usage

``` r
Catalhoyuk
```

## Format

A list with 3 elements :

- StratiConstraints:

  Stratigraphic Matrix for BayLum Adaptation

- C14ages:

  C14 ages

- C14agesEr:

  C14 errors

- C14_Nb_sample:

  C14 sample size

- C14_SampleNames:

  C14 sample names

- Output:

  C14 Ages estimation
